# Jaga Gambut (Laravel)

File di folder ini adalah **tambahan di atas proyek Laravel 11/12 baru** (tanpa vendor/framework).

```bash
composer create-project laravel/laravel jaga-gambut
# salin isi folder ini ke dalam jaga-gambut (timpa routes/web.php)
cd jaga-gambut
php artisan migrate      # tabel users bawaan + scores
php artisan serve
```
Konten (kartu drag & drop, kuis, materi) diedit di `config/gambut.php`.
